Eclipse Animator is a modern animation plugin for Roblox, providing a vast featureset that any animator, no matter what
type of animation they are making, will have support from their tooling.

## Purchase & Install
If you haven't done so already, you will need to purchase the plugin. Eclipse Animator is available for purchase on the
[Creator Store][1] for a one-time fee of $20. Once you have done so, install it from your toolbox inventory in Studio.

[1]: https://create.roblox.com/store/asset/86116556258301/
